# Экскурсия по Санкт-Петербургу

Лендинг для авторских экскурсий: программа, тарифы, отзывы, форма связи.
Сделал на курсе, потом доработал под мобильные и добавил подсчёт стоимости услуг.

**Демо:** https://gerevichdev.github.io/Eduson_Excursion_html/
**Стек:** HTML, CSS, JavaScript. Без фреймворков.

## Что есть
- Адаптив под мобильные (от 320px)
- Подсчёт суммы за доп. услуги на чистом JS
- Форма с полями и выбором тарифа

## Запуск
Просто открыть ссылку в браузере.
